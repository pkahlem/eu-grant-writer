# Security

EU Grant Writer is a set of instructions and reference texts: it runs no code, makes no network requests and stores no data. A concern about it — for example text that could make an assistant behave unsafely, or a quotation that should not be there — can be reported privately to info@s-n-m.eu with "Security" in the subject line, or publicly through [GitHub Issues](https://github.com/pkahlem/eu-grant-writer/issues). Reports are acknowledged within five working days.
